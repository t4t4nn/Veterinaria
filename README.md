# Sistema de Reservas - Veterinaria Patitas Felices

Proyecto desarrollado en C# utilizando Windows Forms y SQL Server LocalDB.

## Descripción

El sistema permite gestionar reservas médicas para una veterinaria mediante dos tipos de usuario:

- Cliente
- Administrador

Cada usuario posee funcionalidades distintas dentro del sistema.

---

## Funcionalidades

### Cliente
- Inicio de sesión
- Registro de reservas
- Ingreso de datos de mascota
- Validaciones de formularios

### Administrador
- Visualización de agendamientos
- Agregar reservas
- Actualizar reservas
- Eliminar reservas
- Filtrar por estado

---

## Tecnologías utilizadas

- C#
- .NET Framework
- Windows Forms
- SQL Server LocalDB
- MVC

---

## Base de Datos

Tablas utilizadas:

- Usuarios
